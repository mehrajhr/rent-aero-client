# RentAero Frontend 🏋️‍♂️

"Rent Sports & Outdoor Gear Instantly"

Rent Aero Frontend is a modern web application built for customers, gear providers, and platform administrators. It interacts seamlessly with the GearUp Backend API to provide smooth equipment browsing, secure checkout, order lifecycle tracking, and comprehensive role-based management dashboards.

## 🛠️ Tech Stack
* **Framework**: Next.js (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS
* **UI Components**: Shadcn UI
* **State & Data Fetching**: React Hooks / Server Actions
